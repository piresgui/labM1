Declaração de uso de IA generativa — Laboratório M1.1
Durante o desenvolvimento do projeto, utilizei o Claude como ferramenta de apoio. Ele foi utilizado principalmente para revisar o código, identificar possíveis erros e auxiliar na realização de testes para verificar se as funcionalidades estavam funcionando corretamente.

Também utilizei a ferramenta para ajudar na organização das pastas e arquivos do projeto, buscando manter uma estrutura mais organizada e facilitar a manutenção do código. Além disso, o Claude foi utilizado como apoio para organizar os commits e manter um histórico mais estruturado no GitHub.

A utilização da IA teve como objetivo auxiliar no desenvolvimento e na organização do projeto, enquanto a implementação e as decisões finais sobre o código foram realizadas por mim.

Forma de validação: o código foi executado localmente (python -m pytest e execução via python -m pdi_lab para cada operação), as saídas (imagens em images/output/) foram inspecionadas e conferidas manualmente contra os casos sintéticos previstos no enunciado (valores conhecidos de grayscale, saturação em 0 e 255, ordem dos canais) antes da entrega.
